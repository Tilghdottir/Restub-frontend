# Monochrome Commerce — Ticket Resale

## Palette
- Background: #FAFAF7 (warm white)
- Surface / card: #FFFFFF
- Fog gray: #E8E9EB (borders, subdued surfaces)
- Graphite: #292B2F (secondary text, metadata)
- Ink black: #111111 (primary text, action band)
- No chromatic accent — interface chrome is purely achromatic

## Typography
- Display / UI: DM Sans — medium (500) for labels and actions, regular (400) for body
- Data / prices: DM Mono — tabular numerals for all prices, quantities, seat numbers, dates
- No serif faces

## Structure
- 8px border-radius on cards and inputs
- 1px borders in fog gray (#E8E9EB)
- Black-filled selected states
- Persistent solid black action/checkout band anchored to one edge of the screen
- Medium-density layout: clear matrix of modules, rows, and lists
- Event imagery in consistently cropped frames (natural color retained)
- No decorative elevation — structure from borders only

## Signature
A solid black action band anchoring an otherwise pale, highly structured commerce interface. Every price shown in monospaced tabular numerals.
